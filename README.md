## 〜OSMを用いた学生・社会人向け作業スペース共有サイト〜 ##

### 「こにゃーきんぐ」の作成とユーザー向け機能の拡充 ###

概要（2026年11月時点）

本研究では、東京・神奈川のビジネス街や人口密集エリアを中心に、コワーキングスペースや図書館、カフェ、ファストフード店などで「しゃべれるか（会話・Web会議・面接ができるか）」と「充電できるか」を共有できるウェブサイトを、OpenStreetMap（OSM）を用いて開発・運用している。

中間構想発表で教授からいただいたアドバイスを受けて、サイトの軸を 「しゃべれる」作業スペースを探すこと　に絞った。あわせて、OSM に既存のタグがある情報（電源・Wi-Fi・営業時間・店員さんの対応言語）は、サイトからワンクリックで OSM に書き込める仕組み（OSM連携）を作り、利用者がサイトを使うほど OSM の地図データも豊かになるようにした。

投稿データは Firebase に保存し、現地確認によって情報の信頼性を高めながら、外出先で会議・面接・作業ができる場所を探す社会人や就職活動中の学生にとって便利なサイトを目指す。

本研究の問いは、次の3点である。

	1.	既存の OSM で充実していない「話せるか」という情報を、共有地図でどれだけ集められるか
	2.	集めた情報を現地確認によって信頼できるものにし、OSM に還元できるか
	3.	ゲーム・クエスト要素で、利用者の継続的な参加を促せるか
